## 📖 Acerca de este Proyecto

Esta guía está diseñada como una **ruta completa y modular** de aprendizaje tanto para principiantes que dan sus primeros pasos en el control de versiones como para desarrolladores que desean transformar su perfil de GitHub en un portafolio técnico interactivo.

> [!NOTE]
> 📜 Si deseas consultar la versión original de esta guía, se encuentra disponible [**aquí**](./old-version/README.md).

| :--- | :--- | :---: |

| **02. Fundamentos de Git** | Arquitectura de 4 áreas, estados de archivos y conceptos (Commit, Rama, HEAD). | [👉 Leer Módulo 02](./02-fundamentos-de-git.md) |
| **03. Fundamentos de GitHub** | Repositorios remotos, Forks, Pull Requests, Code Review y GitHub Flow. | [👉 Leer Módulo 03](./03-fundamentos-de-github.md) |
| **04. Instalación y Configuración** | Instalación multiplataforma, `git config`, SSH Keys, Tokens (PAT) y GitHub CLI (`gh`). | [👉 Leer Módulo 04](./04-instalacion-y-configuracion.md) |
| **05. Chuleta de Comandos Git** | Cheat sheet con comandos esenciales, avanzados (`switch`, `restore`, `stash`, `rebase`) y solución de conflictos. | [👉 Leer Módulo 05](./05-chuleta-comandos-git.md) |
| **06. Dominando Markdown** | Sintaxis esencial, formato de texto, listas, enlaces, imágenes, videos y tablas completas en Markdown y HTML. | [👉 Leer Módulo 06](./06-dominando-markdown.md) |
| **07. GFM, Mermaid y Avanzado** | Alertas oficiales (`[!NOTE]`, etc.), desplegables `<details>`, teclas `<kbd>`, diagramas Mermaid y fórmulas LaTeX. | [👉 Leer Módulo 07](./07-gfm-mermaid-y-avanzado.md) |
| **08. Estructura de Perfil y Proyectos** | Creación de cuenta, README especial (`username/username`) y estructura profesional de README para proyectos de software. | [👉 Leer Módulo 08](./08-estructura-y-creacion-perfil.md) |
| **09. Badges, Widgets y Métricas** | Contadores de visitas, banners SVG, badges personalizados, widgets de estadísticas, repo cards y gist cards. | [👉 Leer Módulo 09](./09-badges-widgets-y-metricas.md) |
| **10. Perfiles Inspiradores y Plantillas** | Casos reales de perfiles creativos (minimalistas, visuales, gamificados, data/IA), colecciones y acceso a plantillas. | [👉 Leer Módulo 10](./10-perfiles-inspiradores-y-plantillas.md) |
| **11. Automatizaciones con Actions** | GitHub Actions para tu perfil: Snake game, blog RSS, WakaTime, AoC badges, infografías y guestbook. | [👉 Leer Módulo 11](./11-automatizaciones-y-actions.md) |
| **12. Recursos y Curaduría** | Selección de los mejores videos con miniatura, cursos gratuitos, plataformas interactivas y libros recomendados. | [👉 Leer Módulo 12](./12-recursos-y-curaduria.md) |
