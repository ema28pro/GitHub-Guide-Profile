| Plataforma | ¿Por qué es genial? | Enlace |
| :--- | :--- | :---: |
| **Learn Git Branching** | La herramienta visual #1 del mundo para dominar ramas, rebase y cherry-pick en un simulador interactivo. | [🌿 Jugar Gratis](https://learngitbranching.js.org/?locale=es_AR) |

| **Git Immersion** | Un recorrido guiado paso a paso con 50 ejercicios prácticos breves. | [📚 Comenzar](https://gitimmersion.com/) |


## 📚 3. Libros, Documentación y Tutoriales de Markdown

- 📕 **[Pro Git Book (Oficial)](https://git-scm.com/book/es/v2)**: El libro de referencia definitivo escrito por Scott Chacon y Ben Straub, disponible gratis en español.
- 🐙 **[Documentación Oficial de GitHub](https://docs.github.com/es)**: Guías oficiales y actualizadas sobre todas las funciones de GitHub.
- 📖 **[Tutorial Markdown](https://tutorialmarkdown.com/)**: Guía interactiva paso a paso para dominar la sintaxis.
- 🎓 **[Curso de Markdown por Luis Llamas](https://www.luisllamas.es/curso-markdown/)**: Tutorial detallado con trucos avanzados.
- 🖼️ **[Guía de Imágenes en Markdown (Denshub)](https://denshub.com/es/hugo-post-insert-image/)**: Todo sobre inserción y gestión de imágenes.
- 📝 **[Especificación GitHub Flavored Markdown (GFM)](https://github.github.com/gfm/)**: La referencia técnica oficial de la sintaxis soportada.
- 📊 **[GitHub Cheat Sheet Oficial (PDF)](https://training.github.com/downloads/es_ES/github-git-cheat-sheet.pdf)**: Hoja de referencia rápida para imprimir.


## 🛠️ 4. Catálogo de Herramientas y Generadores para tu Perfil

- 📊 **[GitHub Metrics (lowlighter)](https://github.com/lowlighter/metrics)**: Potente generador de infografías con más de 40 plugins de métricas y hábitos.
- ⏱️ **[Waka Readme Stats (anmol098)](https://github.com/anmol098/waka-readme-stats)**: Inyecta estadísticas de tiempo de desarrollo en texto y barras ASCII.
- 📖 **[GitHub Profile Guestbook (Livio Brunner)](https://github.com/BrunnerLivio)**: Libro de visitas interactivo donde los usuarios firman vía Issues.
- 📰 **[Profile Auto-builder (Simon Willison)](https://github.com/simonw)**: Patrón de auto-actualización de releases, TILs y artículos con Python.
- 🎨 **[Animated Profile README Guide (Avi Vashishta)](https://www.avivashishta.com/blog/build-animated-github-profile-readme.html)**: Tutorial para construir tarjetas SVG animadas con arte ASCII.
- 🌐 **[Top GitHub Users (Gayan Voice)](https://github.com/gayanvoice/top-github-users)**: Rankings públicos y automáticos de los usuarios de GitHub más activos por país y ciudad.
- 🌊 **[Capsule Render (kyechan99)](https://github.com/kyechan99/capsule-render)**: Cabeceras y pies de página decorativos SVG con ondas y degradados.
- 🎨 **[SVG Banners (Akshay090)](https://github.com/Akshay090/svg-banners)**: Generador de banners SVG dinámicos y estilizados para cabeceras.
- 🏷️ **[Badges4-README (Alexandre Sanlim)](https://github.com/alexandresanlim/Badges4-README.md-Profile-Dynamic)**: Catálogo masivo y clasificado de insignias para perfiles.
- ⚡ **[AoC Badges Action (J0B10)](https://github.com/J0B10/aoc-badges-action)**: GitHub Action para generar e inyectar badges automáticos en tu README.
- 📜 **[Gists Readme (Yizack)](https://github.com/yizack/gists-readme)**: Tarjeta de estadísticas globales para GitHub Gists.
- 🏆 **[GitHub Profile Trophy (ryo-ma)](https://github.com/ryo-ma/github-profile-trophy)**: Logros y trofeos dinámicos en GitHub.
- 🧠 **[LeetCode Stats Card (JacobLinCool)](https://github.com/JacobLinCool/LeetCode-Stats-Card)**: Tarjeta de problemas resueltos y ranking de LeetCode.
- 🎧 **[Spotify Recently Played (kittinan)](https://github.com/kittinan/spotify-github-profile)**: Muestra en vivo canciones y artistas escuchados en Spotify.
- 🧊 **[GitHub Profile 3D Contrib (yoshi389111)](https://github.com/yoshi389111/github-profile-3d-contrib)**: Calendario de contribuciones en 3D interactivo.
- 📊 **[GitHub Stats Extended](https://github.com/stats-organization/github-stats-extended)**: Sucesor activo y estable para generar tarjetas de estadísticas, lenguajes, WakaTime, Repo Cards y Gist Cards.
- 🪄 **[GitHub-Stats-Extended Wizard](https://github-stats-extended.vercel.app/frontend)**: Generador visual interactivo para diseñar tus tarjetas de estadísticas.
- 📈 **[GitHub Readme Activity Graph](https://github.com/Ashutosh00710/github-readme-activity-graph)**: Gráfico de actividad anual interactivo.
- 🔥 **[GitHub Streak Stats (Demolab)](https://streak-stats.demolab.com/)**: Contador de racha diaria de contribuciones.
- 🏷️ **[Skill Icons](https://skillicons.dev/)**: Iconos modernos de tecnologías para tu README.
- 🛡️ **[Shields.io](https://shields.io/)**: Generador universal de insignias y badges SVG.
- ⌨️ **[Readme Typing SVG](https://readme-typing-svg.demolab.com/demo/)**: Efecto de máquina de escribir animado.
- 🏷️ **[Profile Technology Icons (marwin1991)](https://github.com/marwin1991/profile-technology-icons)**: Colección estandarizada de más de 500 iconos de tecnologías para perfiles.
- ✨ **[Tech Stack Generator](https://techstack-generator.vercel.app/)**: Generador visual de iconos animados de tecnologías para el README.
- 🎨 **[Devicon](https://devicon.dev/)**: Logos oficiales de herramientas y lenguajes de programación en SVG.
- 🎨 **[Simple Icons](https://simpleicons.org/)**: Catálogo de más de 3,000 iconos SVG de marcas y tecnologías.
- 🤖 **[Profile README Generator](https://rahuldkjain.github.io/gh-profile-readme-generator/)**: Generador visual de perfiles.
